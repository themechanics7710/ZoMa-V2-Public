# Mechanical

CAD and cut files for ZoMa's chassis, and 3D-printable design files for the
printed parts referenced throughout the build. See
[`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) for the mechanical layout and
[`docs/EQUIPMENT.md`](../docs/EQUIPMENT.md) for which part is used on which
build day.

- **[`3d_design/`](3d_design/)** — 3D-printable design files: the TX
  controller case, chassis edge profiles, the mast cap, and brackets.
